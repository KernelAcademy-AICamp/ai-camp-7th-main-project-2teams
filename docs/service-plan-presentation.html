06 — 실험 및 검증

정보는 같고, '재발견 구조'만 다르게

같은 북마크 세트를 주고 되찾는 경로만 바꾼다. 저장량이 아니라 재발견 행동이 늘어나는지 하나만 본다.

A안

폴더 · 키워드 검색

  • 기존 방식
  • 제목 기반 매칭
  • 수동 분류 의존
vs
B안

모와바 자연어 검색

  • 의미 기반 벡터 검색
  • 자동 태깅
  • 구조화된 재발견
판정 — MAU 중 자연어 검색 사용률 40% 넘으면 Go 보조 관측 — 검색 클릭률 · 재발견 소요시간 + 정성 인터뷰 관측 시작 2026-08-04 · 표본 수와 기간은 초기 사용자 확보 후 확정

사용자 A/B는 배포 후 구간이지만, 내부 A/B는 이미 돌렸다 — 임베딩 모델을 3-small에서 3-large로 바꿔 recall@10 0.70 → 0.85 (AI/ML 북마크 233건 실측). 가르는 방식은 검증된 상태다.
